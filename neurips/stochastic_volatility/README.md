# Rough Bergomi — NeurIPS

This is the active implementation of the main-text rough Bergomi experiment (`table:rough_bergomi`). The other six volatility models, their datasets and records, and the later 132-evaluation runs have moved to `/home/luke/nsde_archive/volatility_main_text_20260924/`. SIAM does not include this Euclidean experiment.

## Saved manuscript results

The four original rough Bergomi runs remain in [results/neurips_20260421](results/neurips_20260421/README.md): four solvers, seed 0 and 504 generator evaluations per trajectory. Each run retains its checkpoint, predictions, configuration, history and metrics. Regenerate their central errors and runtimes without training:

```bash
./run rough-vol --table
```

Displayed terminal MSE is 100 times raw MSE, and runtime includes training and inference. The script does not regenerate uncertainty intervals. The original seven-model table and its generator are preserved in the archive. The existing MCF Midpoint discrepancy remains: saved predictions give 7.82, while the manuscript prints 7.81.

## Training

From the repository root, run:

```bash
./run rough-vol
```

The sweep uses 100 epochs, batch size 4096, hidden width 16, 504 generator evaluations, four solvers and seed 0. Add `--index N` to select one of its four configurations. The dataset is `data/rough_bergomi_data.npz`, split 70/15/15. Settings are in [configs/stoch_vol/sweep.toml](configs/stoch_vol/sweep.toml); use `--config PATH` to override them. The launcher selects uv dependencies and writes each sweep under a fresh `results/runs/<timestamp>/` directory.

The dependencies now use Georax's compatible Diffrax-lowstorage revision. Existing records retain their original library provenance; they have not been regenerated by this migration. The fixed-step runs and earlier diagnostics remain in `/home/luke/nsde_archive/experiments/stochastic_volatility/`, and the complete predecessor implementation remains in `/home/luke/archive/neural-sde-predecessors-20260924/`.
